# AION Kinder — 부모교육 캐러셀 팩토리 (베트남어)

주제 하나만 바꾸면 **8장짜리 인스타 캐러셀**이 자동으로 나오는 공장입니다.
AI 이미지·영상을 쓰지 않으므로 **생성 비용 0원**이고, 디자인은 매번 100% 똑같이 나옵니다.

---

## 왜 영상이 아니라 캐러셀인가

| | 캐러셀 (지금 이것) | 숏폼 영상 |
|---|---|---|
| 편당 비용 | **0원** | 수천~수만 원 |
| 디자인 재현성 | **100% 동일** | 매번 다르게 나옴 |
| 제작 시간 | **수 초** | 수십 분 |
| 부모교육 적합도 | 높음 (저장·공유됨) | 보통 |

영상은 **캐러셀로 반응 좋은 주제가 검증된 뒤에** 얹는 것이 순서입니다.
대본(`topics/*.json`)을 공용으로 쓰면 나중에 같은 내용을 영상으로 승격할 수 있습니다.

---

## 폴더 구조

```
aion-parenting-carousel/
├── topics/          ← 주제 파일 (글만 들어있음) ★ 여기만 건드리면 됨
│   └── vn-001-lam-vo-bat.json
├── build.mjs        ← 슬라이드 생성기 (디자인을 결정하는 코드)
├── upload.sh        ← 구글드라이브 업로드
├── fonts/           ← Be Vietnam Pro (베트남어 성조 전용 폰트)
└── out/             ← 결과물이 여기 나옴 (저장소에는 안 올라감)
    └── vn-001-lam-vo-bat/
        ├── slide-01.png ~ slide-08.png   ← 발행용 (인스타 업로드)
        └── vn-001-...-review.pdf         ← 팀 검토용 (8장 한 파일)
```

**핵심 설계:** 글(`topics/*.json`)과 디자인(`build.mjs`)이 분리돼 있습니다.
주제를 100개 만들어도 브랜드 룩은 한 픽셀도 흔들리지 않습니다.

---

## 새 주제 만드는 법 (비개발자용)

### 1단계 — 주제 파일 복사
`topics/vn-001-lam-vo-bat.json` 을 복사해서 `topics/vn-002-<주제이름>.json` 으로 저장.

### 2단계 — 내용만 베트남어로 교체
파일 안의 8개 칸을 채웁니다. **구조는 절대 바꾸지 마세요.**

| 칸 | 무엇을 쓰나 | 슬라이드 |
|---|---|---|
| `cover` | 훅 질문 (스크롤 멈추게) | 1장 |
| `situation` | 흔히 겪는 상황 묘사 | 2장 |
| `dont` | 부모가 보통 하는 반응 3개 | 3장 |
| `why` | 왜 안 되는지 3가지 | 4장 |
| `do` | 올바른 3단계 | 5장 |
| `script` | 그대로 따라 할 대사 | 6장 |
| `summary` | 기억할 3가지 | 7장 |
| `cta` | 저장 유도 + 브랜드 | 8장 |

> ⚠️ `id` 값은 파일 이름과 똑같이 맞춰주세요. 결과 폴더 이름이 됩니다.

### 3단계 — 생성 (명령어 한 줄)
```bash
cd aion-parenting-carousel
node build.mjs topics/vn-002-<주제이름>.json
```
→ `out/vn-002-<주제이름>/` 에 PNG 8장 + 검토용 PDF가 생깁니다.

### 4단계 — 팀 검토 (구글드라이브)
아래 "검토 프로세스" 참고.

---

## 검토 프로세스 (구글드라이브)

📁 **부모 폴더:** `AION Kinder — 부모교육 콘텐츠 (VN)`

주제마다 폴더를 하나 만들고 2가지를 올립니다:

| 파일 | 용도 | 팀이 하는 일 |
|---|---|---|
| `[검토] ... 카피 검토서` (구글 문서) | 베트남어 **글** 검토 | 문장에 **댓글**로 수정 의견 |
| `...-review.pdf` | **디자인** 확인 | PDF에 댓글 |

**왜 글과 디자인을 나눴나?**
디자인은 코드가 고정하므로 매번 검토할 필요가 없습니다. 실제로 검토가 필요한 건
**베트남어 카피**(번역투·말투·문화 적합성)입니다. 그래서 글은 구글 문서에 따로 빼서
문장 단위로 댓글을 달 수 있게 했습니다.

### 승인 흐름
```
초안 생성 → 드라이브 업로드 → 베트남어 검수자 댓글
   → 수정 반영(topics/*.json 고치고 재생성) → 승인
   → 폴더명 앞에 [승인완료] 표기 → 발행
```

> 🔒 **승인 전 발행 금지.** 검토서 맨 아래 승인 확인란에 이름이 채워져야 발행합니다.

## 검토 체크리스트 (베트남어 검수자용)

- [ ] 베트남어가 자연스러운가? (번역투 아닌 실제 엄마들 말투)
- [ ] 호칭이 일관적인가? (`mẹ` / `bạn` / `con` 혼용 주의)
- [ ] 육아 조언이 베트남 문화에 맞는가?
- [ ] 1장 훅이 스크롤을 멈출 만큼 강한가?
- [ ] 오탈자 · **성조 오류** 없는가?

## 기술 메모 (참고용)

- **렌더링:** HTML/CSS → Chromium 헤드리스 스크린샷. 외부 서비스·AI 생성 없음.
- **폰트:** Be Vietnam Pro (베트남어 성조 전용 설계). `fonts/` 에 동봉돼 있어
  인터넷 없이도 항상 같은 결과가 나옵니다.
- **규격:** 1080×1350 (4:5). 인스타 피드 점유율이 가장 큰 비율입니다.
- **검토 PDF:** 글자가 이미지가 아니라 **벡터**로 들어가 용량이 작고 확대해도 선명합니다.

## 자동화 — 주제 파일만 올리면 끝

`.github/workflows/carousel.yml` 이 자동으로 처리합니다.

```
topics/vn-002-xxx.json 을 main 에 올림
        ↓
GitHub 가 슬라이드 8장 + 검토용 PDF 생성
        ↓
구글드라이브에 업로드  (설정돼 있으면)
        ↓
팀이 드라이브에서 검토
```

`build.mjs`(디자인)를 고치면 **모든 주제를 자동으로 다시 생성**합니다.
직접 돌리고 싶을 땐 GitHub → Actions → "캐러셀 생성·업로드" → Run workflow.

> 드라이브 설정을 아직 안 했어도 괜찮습니다. 생성은 되고, 결과물은
> Actions 실행 화면 맨 아래 **Artifacts** 에서 내려받을 수 있습니다.

### 🔑 1회 설정 — 드라이브 연결 (약 5분)

딱 한 번만 하면 그 뒤로는 영원히 자동입니다.

**1단계 · 내 컴퓨터에 rclone 설치**
- Mac: 터미널에 `brew install rclone`
- Windows: https://rclone.org/downloads/ 에서 받아 설치

**2단계 · 구글 계정 인증**
터미널(명령 프롬프트)에 입력:
```bash
rclone authorize "drive"
```
→ 브라우저가 열립니다 → 구글 로그인 → **허용** 클릭
→ 터미널에 `{"access_token":"...","refresh_token":"..."}` 같은 **JSON 한 덩어리**가 나옵니다.
→ 그 **중괄호 `{` 부터 `}` 까지 전부** 복사하세요.

**3단계 · 드라이브 폴더 ID 복사**
구글드라이브에서 `AION Kinder — 부모교육 콘텐츠 (VN)` 폴더를 엽니다.
주소창이 이렇게 생겼을 겁니다:
```
https://drive.google.com/drive/folders/1AbC...XyZ
                                        ^^^^^^^^^ 이 부분이 폴더 ID
```

**4단계 · GitHub에 등록**
저장소 → **Settings** → **Secrets and variables** → **Actions**

`Secrets` 탭에서 **New repository secret** 2개:

| 이름 | 값 |
|---|---|
| `RCLONE_DRIVE_TOKEN` | 2단계에서 복사한 JSON 전체 |
| `DRIVE_PARENT_FOLDER_ID` | 3단계에서 복사한 폴더 ID |

`Variables` 탭에서 **New repository variable** 1개:

| 이름 | 값 |
|---|---|
| `DRIVE_UPLOAD_ENABLED` | `true` |

끝입니다. 이제 주제 파일을 올릴 때마다 드라이브에 자동으로 쌓입니다.

> 🔒 토큰은 GitHub Secrets에만 저장되고 코드에는 절대 남지 않습니다.
> 나중에 연결을 끊고 싶으면 `DRIVE_UPLOAD_ENABLED` 를 `false` 로 바꾸세요.

### 내 컴퓨터에서 직접 올리고 싶다면
```bash
export RCLONE_CONFIG_GDRIVE_TOKEN='{"access_token":...}'
export DRIVE_PARENT_FOLDER_ID='1AbC...XyZ'
./upload.sh vn-001-lam-vo-bat
```
